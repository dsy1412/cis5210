## Course Description

CIS5210 asks how computers reason and act in the world.

The course starts from classical artificial intelligence and later reaches more
contemporary topics.

Known topic areas from Canvas:

- search
- constraint satisfaction problems
- games
- neural networks
- computer vision
- natural language processing

Programming assignments use Python.
